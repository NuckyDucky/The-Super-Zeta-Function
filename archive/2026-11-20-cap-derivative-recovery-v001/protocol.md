# Blind reconstruction from derivatives at the common cap

Fix the published six balanced four-letter words, chronological order, the same cap 1 and L = πi. Use python-flint with 192-bit balls. Randomly shuffle the words, salt the assignment and commit its hash in the input. Send three independently readable measurements per anonymous case: the cap value, first derivative and second derivative (direct Taylor expansion of the four exponentials). Also send the final value at the single outward real nudge h = 2^−24. Each channel is decoded separately. The exact common cap value and slope are public.

The derivative decoder compares each measurement to the corresponding chain-rule polynomial. The single-nudge decoder compares the final value against the second-degree Taylor disk for each of the six words with a common rigorous Cauchy error bound. Make no nearest-guess substitution: a channel is unique only if exactly one word is compatible. Verify all calls against the hidden assignment afterward, including ties. The model family is known; this tests identifiability. For the weight comparison use the existing Dirichlet detector at powers of 2: count one exponent increment per minus and two per plus, then compare recovered prefix parities with the directly computed Taylor derivatives.
